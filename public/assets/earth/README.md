Earth texture maps by Solar System Scope, licensed under CC BY 4.0.

- Original author and license: https://www.solarsystemscope.com/textures/
- License: https://creativecommons.org/licenses/by/4.0/
- The WebP maps were resized and re-encoded from the 4096px maps distributed in the official Three.js Earth example: https://threejs.org/examples/webgpu_tsl_earth.html
- Download source: https://github.com/mrdoob/three.js/tree/dev/examples/textures/planets

The day map provides daylight albedo. The night map provides night illumination. The surface map packs elevation (R), roughness (G), and cloud coverage (B). The portfolio loads the 1024px set on phones and the 2048px set on desktop, and credits the author during the orbit view.
